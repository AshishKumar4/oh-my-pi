Waits on a backgrounded `exec` cell and returns its completion. Use `wait` only after `exec` returns `Script running with cell ID ...`. `cell_id` identifies the running cell. `yield_time_ms` controls how long to wait before yielding again with a progress snapshot (default 10000 ms); if the cell is still running, `wait` may yield again with the same `cell_id`. `terminate: true` stops the running cell instead of waiting. `max_tokens` is accepted but not applied; output is capped by the session. Once the cell has finished, `wait` returns its result and the cell is closed.
