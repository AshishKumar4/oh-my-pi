Send a message to another agent. `to` is an agent name from ListAgents or a background agent id; `message` is plain text. Delivery is immediate and wakes an idle or parked recipient; the receipt names each recipient with `injected`, `woken`, `revived`, or `failed`. `summary` is a transcript label and is not transmitted. `notify_when_idle` is not available in this build; leave it unset.
